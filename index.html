Core Processing Rule

Actual Batch Close: For every POS/device except Clover, the time configured at the device/TMS level determines when the batch actually closes. Clover is the exception: FDPOS controls the batch close.

Funding Flow: The device/TMS must close early enough for the batch data to reach FDPOS. FDPOS must be set before the selected Frontend Next-Day Funding cutoff. When FDPOS minutes are fixed, use the closest available time that still falls before the cutoff.

Sequence: Device/TMS close → data reaches FDPOS → FDPOS meets Frontend cutoff → deposit is eligible for the applicable funding schedule.

Backend Change / Attrition Policy

Agents must not offer backend changes. To move an account from the Omaha Backend to the North Backend, or vice versa, the account must be canceled and boarded again. That cancellation impacts the attrition rate. Every request must be escalated to Back Office + HQ.

Loaded Rules:
